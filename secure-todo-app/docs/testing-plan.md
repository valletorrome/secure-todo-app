# Plan de pruebas

## Pruebas funcionales

| Prueba | Resultado esperado |
|---|---|
| Crear tarea | La tarea aparece correctamente |
| Eliminar tarea | La tarea desaparece |
| Añadir varias tareas | La aplicación mantiene estabilidad |

## Pruebas de seguridad

| Prueba | Resultado esperado |
|---|---|
| Introducir scripts | El sistema no debe ejecutarlos |
| Revisar dependencias | Identificación de vulnerabilidades |
| Verificar Docker | Contenedor funcionando correctamente |

## Evidencias

- Captura de Docker ejecutándose.
- Captura de la aplicación web.
- Captura de PyCharm con estructura del proyecto.
