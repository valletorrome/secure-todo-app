# Ejecución del S-SDLC

## 1. Planificación
Se selecciona una aplicación tipo To-Do ejecutable mediante Docker.

## 2. Requisitos
Se definen requisitos funcionales y de seguridad.

## 3. Diseño seguro
Se crea una estructura organizada separando aplicación, documentación y pruebas.

## 4. Implementación
Se configura Docker y se documentan las medidas de seguridad.

## 5. Pruebas
Se verifica la ejecución correcta y se revisan posibles vulnerabilidades.

## 6. Despliegue
La aplicación se ejecuta mediante Docker Compose.

## 7. Mantenimiento
Se recomienda actualizar dependencias y revisar configuraciones periódicamente.
