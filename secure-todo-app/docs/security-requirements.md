# Requisitos de seguridad

## Objetivo

Definir los requisitos mínimos de seguridad para la aplicación To-Do desarrollada durante la actividad.

## Requisitos funcionales de seguridad

- Validar todas las entradas del usuario.
- Evitar ejecución de scripts maliciosos.
- Proteger la aplicación frente a ataques XSS.
- Mantener dependencias actualizadas.
- Evitar exposición de datos sensibles.
- Utilizar Docker para aislamiento del entorno.

## Requisitos técnicos

- Uso de Docker Compose.
- Separación entre aplicación y documentación.
- Uso de `.gitignore`.
- Uso de contenedores reproducibles.

## Requisitos operativos

- Posibilidad de ejecutar localmente.
- Configuración sencilla.
- Documentación clara de despliegue.
